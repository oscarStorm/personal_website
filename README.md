Personal Website

My personal website and portfolio, built primarily with vanilla JavaScript, HTML, and CSS.

Live site: oscarstorm.dk

About

I'm Oscar Storm, a Computer Science student at Zealand with an interest in backend development, systems programming, and Linux. I use this website to share my projects and experiment with web technologies.

Features

Interactive portfolio — A terminal-inspired profile with text rendered progressively using JavaScript.

Boids simulation — A interactive flocking simulation written in vanilla JavaScript.

Worm simulation — A simulation written in vanilla JavaScript.

Particle simulation - A particle simulation written in Rust.

Browser game — A Godot game running in the browser through WebAssembly, with WebGL rendering.

Visitor analytics — A serverless backend that stores visitor data in a Neon PostgreSQL database.

Tech stack

Frontend: HTML, CSS, JavaScript

Graphics and games: WebGL, Godot, WebAssembly

Backend: Vercel serverless functions

Database: Neon PostgreSQL

Hosting: Vercel
